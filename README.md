# الجاسوس 🕵️

**لعبة اجتماعية جماعية للتخمين والاستنتاج** — النسخة الرقمية من لعبة "الجاسوس" الكلاسيكية.

## نظرة عامة

لعبة أندرويد مبنية بلغة **Kotlin** وواجهة المستخدم **Jetpack Compose**. يجتمع اللاعبون ويتلقى كل منهم دوراً سرياً (بريء أو جاسوس). يتم إعطاء الأبرياء كلمة سرية، بينما يحصل الجاسوس على تلميح فقط. يجب على الجميع مناقشة واستنتاج من هو الجاسوس دون كشف دورهم.

## الأدوار

- **الأبرياء** — يعرفون الكلمة السرية ويجب عليهم اكتشاف الجاسوس.
- **الجواسيس** — لا يعرفون الكلمة السرية، فقط تلميح. يجب عليهم التظاهر بأنهم يعرفون الكلمة والتهرب من الشكوك.

## طريقة اللعب

1. **الإعداد** — اختر عدد اللاعبين (3+) وعدد الجواسيس (1+) وفئات الكلمات.
2. **الكشف** — يتناوب اللاعبون على الاطلاع على أدوارهم وكلمتهم الخاصة.
3. **النقاش** — يناقش الجميع الكلمة ويتداولون حول هوية الجاسوس.
4. **التصويت** — يصوت الجميع على من يعتقدون أنه الجاسوس.
5. **النتيجة** — يتم الكشف عن الأدوار والكلمة وإعلان الفائز.

## الشاشات

| الشاشة | الوصف |
|---|---|
| **الصفحة الرئيسية** | قائمة البدء، فئات مخصصة، كيفية اللعب، لوحة النتائج، مجموعات الأسماء |
| **إعداد اللعبة** | اختيار عدد اللاعبين والجواسيس وفئات الكلمات |
| **كشف الدور** | عرض خاص لكل لاعب لدوره وكلمته |
| **النقاش** | عرض الكلمة وبدء النقاش والتصويت |
| **النتيجة** | عرض الفائز والأدوار والكلمة والفئة |
| **الفئات المخصصة** | إنشاء وإدارة فئات كلمات مخصصة |

## التقنيات المستخدمة

- **اللغة:** Kotlin 2.2
- **واجهة المستخدم:** Jetpack Compose + Material 3
- **البيانات المحلية:** Room DB (SQLite)
- **الشبكات:** Retrofit + Moshi + OkHttp
- **الذكاء الاصطناعي:** Firebase AI (Vertex AI / Gemini)
- **الاختبارات:** JUnit + Robolectric + Roborazzi
- **السمة:** Dark mode بألوان مستوحاة من iOS 18

## المتطلبات

- **Android:** الإصدار 7.0 Nougat (API 24) فما فوق
- **Build:** Gradle مع Kotlin DSL
