# AlJasoosGame - Imposter Game

An Arabic social deduction party game for Android, built with Jetpack Compose.

## Tech Stack

- **Language:** Kotlin
- **UI Framework:** Jetpack Compose (Material 3)
- **Architecture:** Android with Compose
- **Networking:** Retrofit + OkHttp + Moshi
- **Database:** Room
- **Build:** Gradle with Kotlin DSL + Version Catalog

## Requirements

- Android SDK 24+
- Android Studio (recommended for development)
- JDK 17+

## Build

```bash
./gradlew assembleDebug
```
